# NEVAEH'S LIGHTHOUSE

**A safe place to be heard — when nothing else is open.**

NEVAEH is the light. BEACON is the wall. Together they hold space for people in their hardest moments.

---

## What This Is

A conversational mental-health companion built on crisis-first architecture. NEVAEH listens; BEACON watches every word for signals the user may be in danger, and surfaces real help when it matters.

- **Frontend:** React (Vercel)
- **Database:** Supabase (Postgres + RLS)
- **AI:** Claude API
- **Crisis layer:** BEACON protocols (tiered detection + response)

---

## Safety First

Every session runs through BEACON's crisis-detection protocol. Any signal of self-harm, suicidal ideation, violence, or overdose triggers immediate resource surfacing:

- **988** — Suicide & Crisis Lifeline (call or text)
- **Crisis Text Line** — text HOME to 741741
- **911** — for immediate physical danger

NEVAEH is not a replacement for emergency services or professional clinical care. She is a presence.
